# 🏨 AtliQ Hotels Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing hotel booking data for AtliQ Hotels using Python and Pandas. The goal of the project is to perform data cleaning, transformation, exploration, and generate business insights from hotel booking datasets.

[file: Hospital Analysis ](./https://github.com/prachikarsrung/Hospital_Analysis-Python-/blob/main/exercise_solution.pdf)

The analysis helps understand:

* Occupancy trends
* Revenue performance
* Booking patterns
* Customer behavior
* City-wise hotel performance

---

## 📂 Dataset Information

The project uses the following datasets:

* `dim_date.csv`
* `dim_hotels.csv`
* `dim_rooms.csv`
* `fact_aggregated_bookings.csv`
* `fact_bookings.csv`

## 📊 Key Tasks Performed

### 1️⃣ Data Exploration

* Explored booking platforms
* Analyzed room categories
* Checked dataset dimensions
* Studied booking distribution

### 2️⃣ Data Cleaning

* Removed invalid guest records
* Handled missing values
* Detected and removed revenue outliers
* Fixed capacity inconsistencies

### 3️⃣ Data Transformation

* Created occupancy percentage column
* Merged multiple datasets
* Converted data into meaningful formats

### 4️⃣ Insights Generated

* Average occupancy rate by room category
* Occupancy comparison: weekday vs weekend
* City-wise occupancy analysis
* Revenue analysis by city
* Month-wise revenue trends
* Average ratings by city
* Revenue by booking platform

---

## 📈 Key Insights

### 🏙️ Average Occupancy by City

* Delhi showed the highest occupancy rate
* Bangalore had the lowest occupancy

### 📅 Weekend vs Weekday

* Weekend occupancy was significantly higher than weekday occupancy

### 💰 Revenue Analysis

* Mumbai generated the highest revenue
* Atliq Exotica contributed the highest hotel revenue

### ⭐ Customer Ratings

* Delhi received the highest average customer ratings
